# Tenants Feature

## Overview
This module manages tenant information, including creation, listing, and detailed views of tenants.

## Structure
- `List/`: Components and pages for listing tenants.
- `Detail/`: Components and pages for viewing tenant details.
- `Create/`: Components and pages for registering new tenants.
- `Edit/`: Components and pages for updating tenant information.
- `Dashboard/`: Tenant-specific dashboard views.

## Usage
Use this feature to manage tenant relationships and link them to properties and units.
