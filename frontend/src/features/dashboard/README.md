# Dashboard Feature

## Overview
This module contains the main dashboard views and components, providing an overview of the application's key metrics and activities.

## Structure
- `DashboardEnhanced/`: The main dashboard container component.
- `StatsSection/`: Components for displaying statistical summaries.
- `ChartsCarousel/`: Carousel component for displaying various charts.
- `ActivityCard/`: Component for showing recent activities.
- `AlertsSection/`: Component for displaying system alerts and notifications.

## Usage
The `DashboardEnhanced` component is the main entry point for the dashboard route.
