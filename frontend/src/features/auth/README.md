# Auth Feature

## Overview
This module handles all authentication-related functionality, including user login, registration, and session management.

## Structure
- `components/`: UI components specific to authentication (e.g., LoginForm, RegisterForm).
- `hooks/`: Custom hooks for auth logic (e.g., useAuth, useLogin).
- `pages/`: Page components for auth routes (e.g., LoginPage, RegisterPage).

## Usage
Import components or hooks from this feature to implement authentication flows.
