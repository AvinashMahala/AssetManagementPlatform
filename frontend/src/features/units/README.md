# Units Feature

## Overview
This module manages individual units within properties, including their creation, listing, and details.

## Structure
- `List/`: Components and pages for listing units.
- `Detail/`: Components and pages for viewing unit details.
- `Create/`: Components and pages for adding new units.
- `Edit/`: Components and pages for modifying unit details.
- `Dashboard/`: Unit-specific dashboard views.

## Usage
Units are the granular assets managed within properties and assigned to tenants.
