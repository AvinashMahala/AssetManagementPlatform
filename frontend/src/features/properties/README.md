# Properties Feature

## Overview
This module handles property management, allowing users to create, view, edit, and list properties.

## Structure
- `List/`: Components and pages for listing properties.
- `Detail/`: Components and pages for viewing property details.
- `Create/`: Components and pages for creating new properties.
- `Edit/`: Components and pages for editing existing properties.
- `Dashboard/`: Property-specific dashboard views.
- `components/`: Shared components for property features.
- `form/`: Form components for property data entry.
- `utils/`: Utility functions for property data manipulation.

## Usage
This feature is central to the asset management platform, linking properties to units and tenants.
