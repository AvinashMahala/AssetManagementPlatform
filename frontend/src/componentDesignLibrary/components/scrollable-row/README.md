# ScrollableRow

A container that allows horizontal scrolling of its children, with navigation buttons and keyboard support.

## Usage

```tsx
import { ScrollableRow } from './ScrollableRow';

<ScrollableRow title="My Items">
  <div className="w-64 h-32 bg-gray-100">Item 1</div>
  <div className="w-64 h-32 bg-gray-100">Item 2</div>
  <div className="w-64 h-32 bg-gray-100">Item 3</div>
</ScrollableRow>
```
