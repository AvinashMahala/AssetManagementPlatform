# Charts

A collection of chart components using Recharts.

## Components

- `RevenueTrendChart`: Line chart for revenue trends.
- `OccupancyRateChart`: Area chart for occupancy rates.
- `PaymentCollectionChart`: Bar chart for payment collection.
- `PropertyStatusChart`: Pie chart for property status.
- `ComparisonChart`: Multi-line chart for comparing data.

## Usage

```tsx
import { RevenueTrendChart } from './Charts';

<RevenueTrendChart data={data} />
```
